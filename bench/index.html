canvaskit-wasm and skia-wasm

The same frames drawn by canvaskit-wasm (WebGL) and by skia-wasm (WebGPU). Keep this page visible while it runs. Options, in the URL: scenes=rrects,shaders,paths,images, variants=K,I (also the order of the run), frames=600, warmup=120, load=spin. Allocation figures come from the DevTools protocol and are only there when yarn bench runs the page.
