---
title: Examples
description: Skia Graphite on WebGPU, compiled to WebAssembly, one example at a time.
---

Each page runs its example live, then shows its code. An example is a complete module: it expects a page with a 512 by 512 `<canvas>`, served over HTTPS or from localhost, in a browser with WebGPU.

The `skia-wasm` package on npm is still a placeholder. Until it is published, run `yarn build` in the repository and import `dist/lib/index.js` instead.
