Three short guides, then examples. Each example runs live above its code. It is a complete module that expects a page with a 512 by 512 `<canvas>`, served over HTTPS or from localhost, in a browser with WebGPU.

Most examples use the immediate API: a canvas, paints and paths, in the style of CanvasKit, with plain numbers for geometry and CSS strings for colors. The last section is the retained API, the display list.

## Display list
